# 🛍️ SHOPIFY API INTEGRATION GUIDE - ASIAKAS VALMIS

## ✅ Mitä on tehty:
- **Storefront API:** Konfiguroitu ja toimii
- **Mock Data:** Fallback toimii kun API ei vastaa
- **Product Pages:** Dynaamisesti generoidut
- **Checkout:** Stripe integraatio valmis

## 🔧 Asiakas voi lisätä tuotteita:

### 1. Shopify Admin Panel:
1. Mene: `https://herbspot.myshopify.com/admin`
2. **Products** → **Add product**
3. Lisää tuotteet:
   - **Title:** Tuotteen nimi
   - **Description:** Kuvaus
   - **Images:** Tuotekuvat
   - **Price:** Hinta EUR
   - **Tags:** wellness, focus, calm, sleep, recovery

### 2. Tuotteiden kategoriat:
- **510-patruunat** - 510-compatible cartridges
- **yrttiblendit** - Botanical blends
- **wellness-packs** - Starter packs
- **diy-tarvikkeet** - DIY tools
- **laitteet** - Devices

### 3. Automaattinen synkronointi:
- Tuotteet näkyvät sivustolla heti
- SEO-metatiedot generoidaan automaattisesti
- Structured data lisätään automaattisesti

## 🎯 Asiakas ei tarvitse:
- Koodia muuttaa
- Deployausta
- Teknistä tietotaitoa

**Kaikki toimii automaattisesti Shopify Admin Panelin kautta!**
